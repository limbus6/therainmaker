## Interaction-path measurements

Counts start on the Dashboard and end at the next meaningful decision or visible consequence.

| Normal path | Before | After | Reduction |
| --- | ---: | ---: | ---: |
| Start a priority and see its first consequence | 3 clicks (open Tasks, expand, start/advance) | 1 click (Start & Advance) | 67% |
| Respond to a new high/urgent decision email | 3 clicks (open Inbox, select, respond) | 1 click (TurnTape response) | 67% |
| Clear N low-priority informational messages | N clicks | 1 click | N−1 clicks |
| Queue N routine internal/document tasks | 1 + 2N clicks (open Tasks, expand and queue each) | 1 click | 2N clicks |
| Discover why Advance changes the date | navigation/guesswork | 0 extra clicks; reason is beside the CTA | navigation removed |

The raw Advance action now redirects attention to an available priority when no work is in progress. This prevents the ordinary path from accumulating repeated no-choice advances while actionable work is waiting.

## Safeguards

- A message is routine only when it has no response options, is low/normal priority, and is system/market information or low-priority internal mail.
- A task is routine only when it is available (not recommended), low complexity, and internal or document production.
- Relationship, strategic, market-outreach, external-advisor, risk, buyer-selection, dataroom, fee, and SPA decisions are never batched.
- Batch actions queue work; they do not silently complete it or advance time.
- Exact effects remain visible for decision responses. Legacy authored momentum effects are translated to a causal risk input because momentum itself is now derived.

## Validation protocol

- Automated: source hygiene, deterministic event sequence, derived momentum, replay export, save migration, honest effect labels, and routine-batch boundaries.
- Browser smoke test: Dashboard next action, direct Start & Advance, TurnTape decision, Inbox clear, Tasks queue, replay export, and responsive layout.
- Human playtest follow-up: record elapsed time between meaningful decisions over a full mandate and confirm no normal segment contains more than two no-choice advances.
